Prikazuje javnu tražilicu poslovnih subjekata iz centralnog TVRTKE API-ja.

== Installation ==
1. Instalirajte plugin iz ZIP paketa.
2. U Postavke > TVRTKE upišite HTTPS adresu instaliranog API-ja.
3. Dodajte [tvrtke_pretraga] na WordPress stranicu.
4. API mora biti sinkroniziran kako bi pretraga vratila rezultate.

== Notes ==
Ne uključuje samu bazu podataka. Ne šalje OAuth2 tajne pregledniku.
